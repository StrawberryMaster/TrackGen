# [TrackGen](https://strawberrymaster.github.io/TrackGen)

The simplest tropical cyclone track map generator. This is an enhanced fork of [TrackGen](https://trackgen.codingcactus.codes/) by [CodingCactus](https://github.com/Coding-Cactus) — among the changes made here are:

- Support for multiple Blue Marble maps
- Ability to import and export your tracks for usage on other projects, in JSON and HURDAT format
- Support for raw URLs, such as those hosted on Github Gists and Pastebin
- Faster and more optimized rendering of maps
- Dark theme!
- Support for STORMS database files (see [here](https://data.4tu.nl/articles/dataset/STORM_IBTrACS_present_climate_synthetic_tropical_cyclone_tracks/12706085))
- Import track points from a rendered track map image (reverse image → data)
- Full PWA support, letting you use this offline and without having to download a ~250MB map file

## Usage

- Each line is a point to be plotted on the map
- Each field gives information about the point to be plotted

| Field      | Description | Example | Required? |
|:----------:|:------------|:-------:|:---------:|
| Name       | Name of the cyclone, used to join points together | Iota | <ul><li> [ ] No </li></ul> |
| Latitude   | Latitude coordinate, choose either °N or °S instead of using negative numbers | 52 °N | <ul><li> [x] Yes </li></ul> |
| Longitude  | Longitude coordinate, choose either °E or °W instead of using negative numbers | 1°W | <ul><li> [x] Yes </li></ul> |
| Wind Speed | Wind speed at that point, leave blank for unknown speeds | 25 kt | <ul><li> [ ] No </li></ul> |
| Stage      | Stage of tropical cyclone (determines shape used for point) | Tropical Cyclone | <ul><li> [x] Yes </li></ul> |

### Importing tracks from images

The **Import track from image** section (at the bottom of the settings) accepts a track map image — ideally one generated by TrackGen using the default map — via the file picker, drag & drop, or by pasting from the clipboard (Ctrl+V). Detection starts as soon as an image is provided. TrackGen aligns it to the default Blue Marble map, detects the coloured dots/triangles/squares, and loads the result into the manual input form. From there the points can be regenerated, edited, or exported like any manually entered track.

- Alignment is automatic: the image is matched against the bundled default map at several zooms. A preview shows which points were detected and the status line reports the recovered map bounds. If the match confidence is low, coordinates may be inaccurate — especially if the image uses a different base map.
- Dots are found by their flat, uniformly coloured shape (using the expected dot size from the map zoom), not by requiring an exact palette colour. TrackGen's thin white connecting line is used as a cue to prefer real track dots over similarly coloured terrain patches, so other colour schemes still work.
- The colour of a point only encodes its category, so imported wind speeds are representative values for that category (e.g. a mid-range value for Category 2). Dots are matched against the colours of every available scale, and a differently coloured image is still imported by assigning each dot its nearest colour — the status line tells you how many points needed an approximate match.
- The shape encodes the stage: circle → tropical cyclone, square → subtropical cyclone, triangle → extratropical cyclone.
- Names cannot be recovered from an image, so all detected points are imported as one track with the name you enter (default: "Imported Storm"). Multiple storms in a single image become a single connected track.

### Custom color scales

Custom scales start from either the Default or Accessible scale. Add only the speed thresholds where a new color should begin; categories that are not overridden keep the base scale's colors. For example, adding entries at 190 kt and 215 kt creates three C5 ranges: the original C5 color below 190 kt, the first custom color from 190 kt, and the second custom color from 215 kt. The speed unit changes how values are displayed in the editor; its values are stored and applied in knots.
